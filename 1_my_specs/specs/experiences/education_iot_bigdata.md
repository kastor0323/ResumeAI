# 🎓 [IoT 빅데이터 응용 교육과정 6기 (몰입형 실무 양성 과정)]

## 1. 개요 (Overview)
- **기간** : 2024.09 ~ 2024.12 (총 640시간)
- **기관** : 선문대학교 로봇공학플랫폼 연구소
- **역할** : 교육생 및 팀 프로젝트 리더/핵심 개발자

## 2. 상황 / 문제 (Situation & Task)
- **단기 역량 강화** : 4개월이라는 단기간 내에 임베디드, 빅데이터, 웹, AI 등 광범위한 풀스택 기술 역량을 실무 수준으로 끌어올려야 하는 고난도 과정.
- **실무 협업의 부재** : 기존 개인 학습 위주의 방식에서 벗어나, 기업 멘토링 기반의 체계적인 협업 프로세스(Agile, Git Flow 등)를 실제 프로젝트에 이식해야 하는 과제.

## 3. 내가 한 일 (Action)
- **풀스택 기술 스택 내재화** :
  - **Backend** : Spring Boot 및 전자정부표준프레임워크를 활용한 엔터프라이즈급 아키텍처 학습.
  - **Infrastructure** : Linux 기반 빅데이터 플랫폼 구축 및 AWS 클라우드 배포 실습.
  - **Data & AI** : MySQL/Oracle 기반 DB 설계 및 Python을 활용한 인공지능 모델링/데이터 분석 수행.
- **기업 연계 멘토링 프로젝트 수행** : 현업 개발자 멘토링을 통해 실무 요구사항을 분석하고, 이를 기반으로 한 맞춤형 솔루션 기획 및 제작.
- **체계적 협업 프로세스 주도** : GitHub을 활용한 코드 리뷰 및 업무 분산 시스템을 구축하여 팀 프로젝트의 효율성 극대화.

## 4. 정량적/정성적 성과 (Result)
- **경진대회 수상** : 최종 프로젝트 결과물로 **프로젝트 성과물 대회 우수상(2등)** 수상.
- **기술적 도약** : 640시간의 집중 교육을 통해 하드웨어(IoT)부터 소프트웨어(Web/AI)를 아우르는 융합형 개발 역량 확보.
- **실무 준비 완료** : 기업용 프레임워크와 협업 툴에 익숙해짐으로써 현업에 즉시 투입 가능한 수준의 포트폴리오 완성.

## 5. 배운 점 (Lesson Learned)
- **폭발적인 성장 경험** : 단기간에 고강도 프로젝트를 수행하며 한계를 극복하고 새로운 기술을 빠르게 습득하는 '학습 근육'을 길렀음.
- **융합형 사고의 중요성** : IoT 데이터가 백엔드를 거쳐 AI 분석으로 이어지는 전체 파이프라인을 경험하며, 개별 기술이 아닌 '전체 시스템' 관점에서 아키텍처를 바라보는 시야를 갖게 됨.
- **커뮤니케이션의 힘** : 기업 멘토와의 소통을 통해 기술적 구현만큼이나 중요한 것이 '비즈니스 요구사항의 정확한 이해'와 '팀원 간의 조율'임을 깨달음.
