# 🏢 [Java Swing 기반 기업용 인사관리(HR) 시스템]

## 1. 개요 (Overview)
- **기간** : 2023. 09 ~ 2023. 12
- **역할** : 1인 개발 (Full-stack)
- **기술 스택** : `Java (JDK)`, `Swing (GUI)`, `MySQL`, `JDBC`, `DBeaver`

## 2. 상황 / 문제 (Situation & Task)
- **기능적 요구** : 중소기업 환경에서 필요한 직급별 권한 관리와 체계적인 사원 데이터 관리 시스템 부재.
- **기술적 도전** : Java GUI(Swing)와 RDB(MySQL)를 연동하여 실시간으로 데이터를 처리하고, 관리자/일반 사용자에 따른 접근 제어 로직 구현 필요.
- **설계 단계의 어려움** : 초기 개발 시 체계적인 프로세스 부재로 인해 DB 스키마 설계 및 GUI 컴포넌트 배치 구상에서 시행착오 발생.

## 3. 내가 한 일 (Action)
- **요구사항 분석 및 기획** : 인사 행정 프로세스를 분석하여 사원 등록, 수정, 삭제 및 직위/가게별 필터링 기능 명세화.
- **데이터베이스 모델링** : MySQL을 활용하여 사원, 직급, 부서, 권한 테이블 간의 정규화된 관계(Entity Relationship) 설계.
- **GUI 프레임워크 구현** : Java Swing 라이브러리를 사용하여 로그인, 사원 관리 메인, 상세 검색 모듈별 화면 설계 및 이벤트 리스너 구현.
- **권한 제어 로직 개발** : 로그인 세션 정보에 따른 메뉴 활성화/비활성화 및 관리자 전용 데이터 수정 권한 로직 구현.
- **다중 조건 검색 엔진** : SQL 쿼리 최적화를 통해 가게별·직위별 세분화된 검색 필터링 기능 구현.

## 4. 정량적/정성적 성과 (Result)
- **기능 완성** : 사원 정보의 CRUD 전 과정과 권한별 차등 UI 노출 기능 구현 완료.
- **사용자 편의성** : 직관적인 GUI 구성을 통해 비전문가도 쉽게 사용할 수 있는 인사 관리 도구 제작.
- **데이터 무결성** : DB 정규화를 통해 사원 데이터 중복을 방지하고 참조 무결성을 확보한 인사 데이터베이스 구축.

## 5. 배운 점 (Lesson Learned)
- **개발 프로세스의 중요성** : 기획과 DB 설계 등 상위 단계에서의 치밀한 설계가 전체 개발 생산성에 미치는 결정적인 영향을 실감함.
- **풀스택 개발 경험** : 프론트엔드(GUI)부터 백엔드 로직, DB 연동까지 전체 사이클을 직접 수행하며 소프트웨어의 계층별 동작 원리를 깊이 이해함.
- **역량 진단 및 성장** : 코드 구조화와 예외 처리의 중요성을 깨닫고, 향후 유지보수가 용이한 코드를 작성하기 위한 학습 방향(Clean Code, Design Pattern 등)을 설정하는 계기가 됨.
