# 📖 상황 (Situation)
개인 투자자들의 감정적 의사결정과 비율 산정의 어려움을 해결하기 위한 지능형 AI 기반 맞춤형 주식 포트폴리오 리밸런싱 플랫폼을 4인(BE/AI 겸임 1명, AI 2명, FE 1명) 규모로 개발했습니다. 이 프로젝트에서 저는 서버/DB 통신 인프라를 총괄하는 **Backend 엔지니어의 역할**과 더불어, 논문/특허 출원의 바탕이 된 **핵심 딥러닝(AI) 추론 엔진 개발 파트**의 중추적인 역할을 병행하여 융합인재로서의 전문성을 입증했습니다.

# 🎯 과제 (Task)
1. **차별화된 AI 융합 엔진 구축**: 주식 간 동적 관계를 학습하는 TGNN 알고리즘과 최적의 비율 추천을 위한 DDPG 강화학습 모델을 하이브리드로 결합하여 실효성 있는 파이프라인 개발.
2. **복잡한 금융 도메인의 시스템 아키텍처 수립**: Spring Boot(Java 17) 기반으로 안전하고 확장에 용이한 인프라와 더불어 대규모 AI 분석 이력을 담을 수 있는 데이터베이스 구조 설계.
3. **효율적인 MSA 비동기 연동**: Codef API를 통한 실시간 증권 계좌 연동 구축 및, Spring(웹) - Flask(AI 서버) 간의 이기종 API 통신 및 보안/캐시 아키텍처 확립.

# 🚀 행동 (Action)
*   **하이브리드 AI 모델 구축 및 검증**: Temporal Graph Neural Network(TGNN)를 활용하여 시계열 데이터와 관계성을 동시에 훈련하고, DDPG 강화학습으로 자산 배분을 시행하는 모델을 구현해 S&P 500 데이터 기반(2021~2025) 체계적인 백테스팅 비교 검증을 진행했습니다.
*   **1~3정규화 기반 DB 재설계 및 병목 해소**: 잦은 데이터 삽입/삭제 시 발생하는 쿼리 지연 문제를 해결하기 위해 ERD 3차 정규화 및 외래 키(FK) 참조 분리를 통해 구조적 무결성을 회복했습니다. 또한 Spring Boot 서버와 대량 연산인 AI 추론 서버 간 데이터를 넘길 때 비동기 통신 아키텍처를 세우고 이메일 인증/세션 제어에 Redis 기반 캐시 전략을 적용했습니다.
*   **보안과 토큰 밸런스(Refresh/Access Token) 타협점 도출**: 초기 JWT 토큰 단일 설계의 탈취 위험성을 인지해, Access Token(TTL 15분)과 Redis 파이프라인 기반 Refresh Token(TTL 7일)을 이원화 도입하여 인증 성능 오버헤드를 낮추면서 사용자 경험(UX)과 보안성의 가장 이상적인 트레이드오프를 이뤄냈습니다.

# 🏆 결과 (Result)
*   제안한 하이브리드 AI 모델은 기존 BiLSTM 대비 **MSE 단위를 81% 개선**해 예측 정확도 **R² 0.9896**의 훌륭한 수준을 기록했으며, S&P 백테스팅 결과 **연평균 수익률(CAGR) 9.3%와 안정적 리스크율 MDD(-25.2%)**를 고스란히 증명해냈습니다.
*   데이터베이스와 AI 기술의 성공적인 융합 가능성을 인정받아 **산학 연계 우수 프로젝트 동상(4위)을 수상하고, 하이브리드 AI 알고리즘의 실용화 특허를 출원 완료(논문 작성 진행)**했습니다.
*   백엔드 로직 설계에 멈추지 않고 AI 학습 모델 설계부터 런타임 프로덕션급 비동기 파이프라인 통신까지 책임진 결과, '데이터의 근원적 흐름을 구축하는 융합 엔지니어'로서 지향할 아키텍처 식견을 대폭 넓혔습니다.
