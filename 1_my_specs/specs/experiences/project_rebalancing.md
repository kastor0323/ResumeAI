# 📈 [AI 기반 개인 맞춤형 주식 포트폴리오 리밸런싱 추천 서비스]

## 1. 개요 (Overview)
- **기간** : 2025. 01 ~ 2026. 03
- **역할** : Backend Developer & Database Architect

## 2. 상황 / 문제 (Situation & Task)
- **투자자 페인 포인트** : 개인 투자자들이 감정에 휘둘리는 의사결정과 복잡한 자산 배분 비율 산정에 어려움을 겪음.
- **기술적 도전 과제** : 실시간 금융 데이터(Codef API)와 고도화된 AI 모델(TGNN, DDPG)을 안정적으로 결합할 백엔드 인프라 필요.
- **DB 이슈** : 초기 설계 시 데이터 중복 및 복합 조회 성능 저하로 인한 삽입/삭제/갱신 이상 현상 발생.
- **보안 이슈** : 단순 JWT 사용 시 토큰 탈취에 따른 보안 취약점 및 사용자 편의성 간의 트레이드오프 발생.

## 3. 내가 한 일 (Action)
- **데이터베이스 아키텍처 설계** : MySQL 기반의 3차 정규화(3NF)를 수행하여 데이터 무결성 확보 및 JPA를 활용한 엔티티 매핑.
- **사용자 인증 및 보안 시스템** : Spring Security와 JWT(Access/Refresh Token) 기반 인증 체계 구축, Redis를 활용한 토큰 관리 및 이메일 인증 TTL 처리.
- **금융 데이터 파이프라인 구축** : Codef API를 연동하여 국내 주요 증권사 계좌 정보를 실시간 동기화하고 다중 계좌 통합 View API 구현.
- **AI 모델 서빙 연동** : Flask 기반 AI 서버와 RESTful API 통신을 구현하여 TGNN Score 및 DDPG 추천 비율을 비동기적으로 처리 및 히스토리 관리.
- **인프라 최적화** : Redis 캐싱을 통한 API 응답 성능 개선 및 확장 가능한 계층형 아키텍처(Controller-Service-Repository) 설계.

## 4. 정량적/정성적 성과 (Result)
- **수상** : 2025년 1학기 기업연계 프로젝트 우수팀 경진대회 **동상(4등) 수상**.
- **성과** : 하이브리드 AI 모델 **특허 출원** 및 관련 논문 작성 진행.
  - **모델 성능** : TGNN 모델 예측 정확도 MSE 2.02 달성 (기존 CNN-LSTM 대비 **60% 개선**).
  - **수익률** : 백테스팅 결과 하이브리드 모델 기준 연간(Annual) 리밸런싱 시 **CAGR 9.3%**, MDD -25.2%의 안정적 성과 확인.
  - **시스템 안정성** : 정규화를 통한 데이터 이상 현상 제거 및 Redis 도입으로 보안성과 UX 동시 확보.

## 5. 배운 점 (Lesson Learned)
- **DB 설계의 정교함** : 단순 CRUD를 넘어 정규화와 인덱싱 전략이 시스템의 확장성과 무결성에 미치는 결정적인 영향을 체득함.
- **보안과 UX의 균형** : 보안 강화가 사용자 경험을 해치지 않도록 Refresh Token과 Redis를 조합하는 실무적 솔루션 역량을 갖춤.
- **융합형 개발 역량** : AI 모델(TGNN, DDPG)의 특성을 이해하고 이를 백엔드 시스템과 효율적으로 결합하는 데이터 파이프라인 설계 경험을 쌓음.
- **협업의 가치** : API 명세 문서화(Notion)와 정기 스크럼을 통해 프론트엔드 및 AI 파트와 기술적 간극을 줄이는 소통의 중요성을 깨달음.
