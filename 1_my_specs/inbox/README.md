# 📥 Inbox - Specs 업데이트용 원시 자료 폴더

이 폴더에 새로운 경험/프로젝트/역량 관련 내용을 자유롭게 작성해서 저장하세요.

`/SpecsUpdate` 명령어를 실행하면 AI가 자동으로:
1. 이 폴더의 파일들을 분석
2. 기존 specs와 중복 검사
3. 새로운 내용은 specs에 추가
4. 처리 완료된 파일은 삭제

---

## 작성 가이드

### 최소 포함 정보
```
[프로젝트/경험 이름]
- 기간: 
- 역할: 
- 상황/문제: 
- 내가 한 일: 
- 결과: 
- 배운 점: 
```

### 파일 형식
- `.md` 또는 `.txt`
- 파일명은 자유 (예: `새프로젝트.md`, `메모.txt`)

---

## 예시

```
인턴십 - ABC회사
- 기간: 2025.01~2025.02
- 역할: 백엔드 개발 인턴
- 상황: 레거시 시스템 성능 저하 문제
- 내가 한 일: DB 쿼리 최적화, 캐싱 레이어 추가
- 결과: API 응답시간 40% 개선
- 배운 점: 실무 코드베이스 경험, 코드 리뷰 문화
```
