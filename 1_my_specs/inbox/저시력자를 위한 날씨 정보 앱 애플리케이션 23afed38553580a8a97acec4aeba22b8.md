# 저시력자를 위한 날씨 정보 앱 애플리케이션

프로젝트 기간: 2024년 3월 1일 → 2024년 6월 19일
프로젝트 인원: 프로젝트 인원 : 3명(FE 1명 BE 2명(본인))
역할: 서버 구축, 팀원
상태: 완료
사용한 기술: Expo, Expo Snack, GitHub, JavaScript, Python, React, Visual Studio Code
사용한 도구: Expo, Expo Snack
Github: https://github.com/kastor0323/WeatherSearchAPP

### 📖 프로젝트 소개

**저시력자 날씨 알림 앱**은 시각장애인 및 저시력자의 일상 편의를 위해 개발된 **접근성 중심의 모바일 애플리케이션**입니다.

**Weather API**와 **GPS 기능**을 연동하여 사용자의 현재 위치 기반 실시간 날씨 정보를 제공하며, **TTS(Text-to-Speech) 기능**을 통해 음성으로 날씨 정보를 전달하는 것이 핵심 특징입니다.

**React Native**와 **Expo** 프레임워크를 활용하여 크로스 플랫폼 모바일 앱으로 개발한  프로젝트입니다.

### 🙋‍♂️ 주요 업무

- **프로젝트 팀장**: 3명 팀원의 일정 관리 및 업무 분담, 프로젝트 전체 진행 상황 관리
- **서비스 기획 및 설계**: 저시력자 사용자 니즈 분석 및 서비스 요구사항 정의, UI/UX 접근성 가이드라인 수립
- **Weather API 연동**: 외부 날씨 API 서버와의 연결 및 데이터 처리 로직 구현
- **프론트엔드/백엔드 개발**: React Native 기반 모바일 앱 UI 구현 및 백엔드 서비스 로직 개발
- **개발 문서 작성**: WBS, 요구사항 명세서, 시스템 설계도 등 체계적인 프로젝트 문서화

### 🐛 트러블 슈팅

- **API 호출 횟수 제한 문제**
- 문제: Weather API의 일일 호출 횟수 제한으로 인한 서비스 중단 발생
- 해결: 로컬 캐싱 시스템 도입 및 API 호출 최적화를 통해 불필요한 요청 최소화

**TTS 기능 디바이스별 호환성 이슈**

- 문제: iOS와 Android 간 TTS 엔진 차이로 인한 음성 출력 품질 차이 발생
- 해결: 플랫폼별 TTS 설정을 분리하고 음성 속도 및 톤 조절 기능 추가로 사용성 개선

**GPS 위치 정확도 문제**

- 문제: 실내에서 GPS 신호 약화로 인한 위치 정보 부정확
- 해결: 네트워크 기반 위치 서비스를 백업으로 활용하는 하이브리드 위치 추적 시스템 구현
