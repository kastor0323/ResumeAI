# 패스트푸드 가게 인사관리 프로그램

프로젝트 기간: 2023년 9월 1일 → 2023년 12월 22일
프로젝트 인원: 프로젝트 인원 : 1명(개인)
상태: 완료
사용한 기술: Backend : Java8
DATA : MySQL(RDS)
사용한 도구: VScode
Github: https://github.com/kastor0323/HRM-with-JAVA

### 📖 프로젝트 소개

**Java 기반 인사관리 프로그램**은 중소기업의 효율적인 인사 업무 처리를 위해 개발된 GUI 기반 데스크톱 애플리케이션입니다.

직급별 권한 관리와 사원 정보의 **CRUD 기능**을 핵심으로 하여, 관리자와 일반 사용자의 접근 권한을 차별화하고 체계적인 인사 데이터 관리가 가능하도록 설계되었습니다.

**MySQL 데이터베이스**와 연동하여 안정적인 데이터 저장 및 검색 기능을 제공하며, 가게별·직위별 세분화된 검색 기능을 통해 사용자의 편의성을 극대화했습니다.

### 🙋‍♂️ 주요 업무

- **서비스 기획 및 요구사항 분석**: 인사관리 업무 프로세스 분석 및 시스템 요구사항 정의
- **데이터베이스 설계 및 구현**: MySQL을 활용한 사원 정보, 직급, 부서별 테이블 설계 및 관계 정의
- **Java GUI 개발**: Swing 라이브러리를 활용한 사용자 인터페이스 설계 및 구현
- **백엔드 로직 구현**: 사원 등록/수정/삭제 기능 및 관리자 권한 접근 제어 로직 개발
- **검색 기능 개발**: 다중 조건 검색을 통해 검색 필터링 기능

### 📄 상세수행 내용

**📋 데이터베이스 설계**

- 사원 정보, 직급, 부서 테이블 간의 정규화된 관계 설계
- 권한별 접근 제어를 위한 사용자 권한 테이블 구현

🖥️ **GUI 구현**

- Java Swing을 활용한 직관적인 사용자 인터페이스 개발
- 로그인 화면, 사원 관리 화면, 검색 화면 등 모듈별 화면 구성

### 🐛 트러블 슈팅
