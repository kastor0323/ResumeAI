## 📖 프로젝트 소개

**자소서 평가 프로그램**은 취업 준비생들이 작성한 자기소개서를 AI 기반으로 분석하고 평가하는 웹 애플리케이션입니다.

자연어 처리 기술과 머신러닝을 활용하여 자소서의 **강점/약점 분석**, **구조적 완성도 평가**, **콘텐츠 품질 검토** 등을 자동화하고, 사용자 맞춤형 개선 가이드를 제공합니다.

**Python 기반 백엔드**에서 텍스트 분석 로직을 처리하고, **React 프론트엔드**를 통해 직관적인 평가 결과를 시각화하며, **MySQL 데이터베이스**에 평가 이력을 저장하여 사용자가 자신의 성장 과정을 추적할 수 있도록 설계되었습니다.

## 🙋‍♂️ 주요 업무

- **서비스 기획 및 요구사항 분석**: 자소서 평가 프로세스 분석 및 AI 기반 평가 시스템 요구사항 정의
- **데이터베이스 설계 및 구현**: MySQL을 활용한 사용자, 평가 결과, 평가 이력 테이블 설계
- **백엔드 API 개발**: Python Flask/FastAPI를 이용한 자소서 분석 엔드포인트 구현
- **AI/NLP 모듈 개발**: OpenAI API 및 자연어 처리 라이브러리를 활용한 텍스트 분석 로직 개발
- **React 프론트엔드 구현**: 사용자 친화적인 대시보드 및 평가 결과 시각화 개발
- **평가 알고리즘 개발**: 맞춤형 평가 점수 계산 및 개선 제안 생성 로직 구현

## 📄 상세수행 내용

### 📋 데이터베이스 설계

- 사용자 정보, 자소서 원문, 평가 결과, 평가 이력 테이블 설계
- 평가 항목(글씨력, 구성력, 설득력, 창의성 등)별 점수 저장 구조 구현
- 사용자별 평가 이력 추적을 위한 관계 설계

### 🔍 AI/NLP 분석 모듈 개발

- **문법 및 스타일 검사**: 맞춤법, 띄어쓰기, 어조 일관성 분석
- **감정 분석**: 텍스트의 긍정/부정/중립 감정 분석
- **키워드 추출**: 자소서에서 주요 역량과 경험 키워드 자동 추출
- **유사도 분석**: 직무별 우수 자소서와의 비교를 통한 관련성 평가
- **구조 분석**: 문단 구성, 논리적 흐름, 완성도 평가

### 🖥️ 프론트엔드 구현

- **자소서 작성/업로드 화면**: 직접 입력 또는 파일 업로드 기능
- **실시간 분석 결과 대시보드**: 점수, 등급, 강점/약점 시각화
- **상세 평가 리포트**: 항목별 피드백 및 개선 제안 표시
- **평가 이력 관리**: 이전 평가 결과 비교 및 진행 상황 추적
- **반응형 UI**: 모바일, 태블릿, 데스크톱 모든 환경 지원

### 🔗 백엔드 API 설계

```
POST   /api/assessment/analyze      - 자소서 분석 요청
GET    /api/assessment/{id}         - 평가 결과 조회
GET    /api/assessment/history/{uid} - 사용자 평가 이력 조회
POST   /api/auth/register           - 사용자 회원가입
POST   /api/auth/login              - 사용자 로그인
DELETE /api/assessment/{id}         - 평가 결과 삭제
```

## 🐛 트러블 슈팅

### 1. NLP 정확도 문제

- **문제**: 초기 자연어 처리 모델의 정확도가 낮아 부정확한 평가 생성
- **해결**: OpenAI API를 활용하여 고도의 언어 이해 능력 확보, 프롬프트 엔지니어링을 통한 평가 정확도 향상

### 2. API 응답 시간 지연

- **문제**: 자소서 분석 요청 시 3~5초 이상의 응답 지연 발생
- **해결**: 비동기 작업 처리(Celery) 도입, 캐싱 메커니즘 적용으로 응답 시간 50% 단축

### 3. 데이터 보안 및 개인정보 보호

- **문제**: 사용자의 자소서 데이터 보안 및 개인정보 보호 필요
- **해결**: JWT 토큰 기반 인증, 데이터 암호화, SQL Injection 방지 등 보안 강화

### 4. 프론트엔드와 백엔드 통신 문제

- **문제**: CORS 에러 및 요청/응답 데이터 형식 불일치
- **해결**: 적절한 CORS 설정, API 문서화(Swagger), 요청/응답 스키마 표준화
