# 📋 모듈형 이력서/자기소개서 관리 시스템

이력서와 자기소개서를 **모듈(specs)**로 관리하고, 지원 회사별로 **조립**하는 시스템입니다.

## 📁 디렉토리 구조

```
자기소개서/
├── 1_my_specs/               # 👤 내 스펙 및 역량 관리 계층
│   ├── inbox/                # 새 경험 메모 (임시 저장소, /SpecsUpdate 반영 전)
│   ├── specs/                # 정규화된 모듈 조각 (base, experiences, competencies 등)
│   └── templates/            # 자주 쓰는 자소서 뼈대 양식
│
├── 2_target_companies/       # 🏢 타겟 회사 정보 관리 계층
│   ├── job_posting/          # 채용 공고 원본 (JD) 텍스트 파일 저장소
│   └── reports/              # AI가 분석한 기업 분석 보고서
│
├── 3_applications/           # 📄 최종 조립본 및 아카이브 (Output)
│   ├── 2026-02-SP정보기술/
│   ├── 2026-02-토스/
│   └── archive/              # 기존 서류 합불 완료본 보관
│
├── .agent/                   # 🤖 AI 에이전트 시스템
│   ├── skills/               # 페르소나 (기업분석가.md, 자소서컨설턴트.md 등)
│   └── workflows/            # 자동화 워크플로우 명령어 (/SpecsUpdate 등)
│
└── README.md                 # 이 파일
```

## 🚀 시작하기 (Getting Started)

본 시스템은 로컬 파일 읽기 및 쓰기가 가능한 **AI 에이전트(Cursor, Cline, GitHub Copilot Workspace 등)** 환경에서 구동하는 것을 강력히 권장합니다.

### 1️⃣ 사전 준비 (Setup)

1. 이 저장소를 로컬에 `git clone` 합니다.
2. **내 스펙(Specs) 초기 구축하기 (2가지 방법 중 택 1)**
   * **방법 A (수동 작성):** `1_my_specs/specs/_templates` 폴더 내의 양식을 직접 복사하여, 경험과 역량을 `1_my_specs/specs/` 하위 폴더들에 직접 작성합니다.
   * **방법 B (AI 자동화 - 추천! ⭐):** 기존에 작성해둔 자기소개서나 경험 정리 본(텍스트)을 `1_my_specs/inbox/` 폴더에 넣고, 에디터 AI 채팅창에 다음과 같이 입력합니다.
     > *"/SpecsUpdate 실행해줘. inbox에 있는 내 기존 자소서들을 분석해서 specs 구조에 맞게 초기 세팅해줘."*
     > AI가 내용을 분석해 모듈별로 알아서 쪼개어 프론트매터 양식에 맞게 `specs/` 폴더 내에 마크다운 파일들을 생성해 줍니다.
     >
3. 지원하려는 기업의 채용 공고나 직무 기술서를 분석하기 위해 `2_target_companies/job_posting/` 폴더에 문서(텍스트) 형태로 저장합니다.

### 2️⃣ 1단계: 기업 분석 및 리포팅

에디터의 AI 채팅창(Cursor 등)을 열고 다음과 같이 텍스트를 입력합니다.

> *"2_target_companies/job_posting/ 에 있는 채용 공고를 바탕으로 기업분석해줘",
> "{링크} 이 채용 공고를 바탕으로 기업분석해줘"*

* **동작 원리:** `.agent/skills/기업분석가.md` 프롬프트가 작동하여, AI가 웹 검색을 통해 비즈니스 모델(BM), 재무 건전성, 워라밸 등을 분석하고 `2_target_companies/reports/` 폴더에 기업 분석 마크다운 보고서를 자동 생성합니다.

### 3️⃣ 2단계: 맞춤형 자소서 자동 조립 (Auto-Assembly)

기업 분석이 끝난 후, 혹은 특정 회사를 타겟으로 동일한 채팅창에 다음과 같이 입력합니다.

> *"분석한 내용을 바탕으로 자소서 작성 시작해줘"*

* **동작 원리:** `.agent/skills/자소서컨설턴트.md` 페르소나 프롬프트가 즉각 작동합니다. AI가 지원자의 `1_my_specs/specs/` 데이터베이스를 뒤져 현재 채용 공고와 가장 적합한 경험(가중치와 직무 적합도 기반)을 선별합니다.
* **결과물:** `3_applications/[YYYY-MM-회사명]/` 폴더에 자소서 초안(`cover_letter.md`)과 어떤 스펙을 왜 썼는지에 대한 메타데이터(`sources.md`)를 작성해 줍니다. 당신은 이 초안을 다듬기만 하면 됩니다.

### 4️⃣ 스펙(Specs) 지속 업데이트

새로운 프로젝트를 마쳤거나 학점이 올랐다면, 정규화된 마크다운을 직접 짤 필요 없이 `1_my_specs/inbox/` 폴더에 텍스트 형태로 메모만 직관적으로 남겨둡니다. 그 후 AI 채팅창에 다음 명령어를 입력합니다.

> *"/SpecsUpdate 실행해줘"*

* **동작 원리:** AI 워크플로우(`/workflows/SpecsUpdate.md`)가 구동되어, 알아서 알맞은 프론트매터 양식과 폴더 위치(`experiences/` 또는 `base/` 등)를 찾아 스펙 모듈을 구조화(`1_my_specs/specs/`)하여 저장합니다.
