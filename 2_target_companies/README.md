# 🏢 2. 타겟 회사 정보 관리 계층 (Target Companies)

이 디렉토리는 내가 지원하고자 하는 **목표 기업의 채용 공고(JD)를 수집**하고, 해당 기업의 비즈니스 모델이나 재무 상태를 **AI가 심층 분석한 리포트를 보관**하는 곳입니다.

---

## 📁 하위 폴더 구조 및 역할

### `job_posting/` (채용 공고 원본)
* **목적:** 타겟 기업의 채용 공고(JD), 지원 자격, 우대 사항 등을 복사해서 텍스트나 마크다운 파일로 저장합니다.
* **사용법:** 예를 들어 `토스_백엔드_JD.txt` 형태로 파일을 저장해 둡니다. 이 파일은 인풋(Input) 데이터가 되어 기업 분석 프로세스의 재료로 사용됩니다.

### `reports/` (기업 분석 보고서)
* **목적:** AI 에이전트(`기업분석가` 스킬)가 생성한 목표 기업의 심층 분석 리포트가 완성되어 저장되는 결과물 폴더입니다.
* **내용:** 비즈니스 모델, 최근 뉴스, 재무 건전성, 20년 뒤 유망도, 워라밸(Work-Life Balance) 및 자소서/면접 공략 포인트가 담깁니다.

---

## 🔄 워크플로우 요약
1. 원티드, 사람인 등에서 마음에 드는 채용 공고 텍스트를 긁어서 `job_posting/` 폴더에 `[회사명].txt`로 저장합니다.
2. AI 채팅창에 **"job_posting/ 에 있는 채용 공고 바탕으로 기업분석해줘"** 라고 명령합니다.
3. AI가 웹 검색을 마치고 `reports/` 폴더에 마크다운 리포트를 깔끔하게 자동 생성해 줍니다!
