## 1. 본인의 지식 및 기술역량을 지원직무 수행 시 어떻게 발휘할 수 있을지 설명해 주세요. (최소 300자, 최대 700자)
*작성방법 : ① 지식 및 기술역량 ② 해당 역량을 어떻게 발휘할 수 있을지에 관한 내용 포함*

**[안정적 트랜잭션을 담보하는 동시성 제어 역량]**
Spring Boot 기반의 백엔드 분산 아키텍처 설계 및 대용량 트래픽 환경에서의 데이터 동시성 제어 역량을 보유하고 있습니다. 주식 거래 시스템 구축 당시, Trading API와 리스크 관리 모듈 개발을 전담하며 트랜잭션 신뢰성을 극대화했습니다. 동일 사용자의 주문 중복 요청을 방지하고자 Redis 1차 락과 DB UNIQUE 제약조건을 활용해 이중 멱등성 안전망을 구축했습니다. 또한, 다중 인스턴스 환경에서 동일 계정의 체결 데이터 동시 처리 시 발생하는 경쟁 조건을 해결하기 위해 Redis 분산 락을 설계·적용하여 원장 불일치 0건을 검증해냈습니다.

이러한 기술 역량을 바탕으로 홈쇼핑IS팀에서 다음과 같이 발휘하겠습니다. 첫째, 방송 송출 및 프로모션 시 발생할 수 있는 주문/결제 동시 요청 급증 상황에서 분산 동시성 제어를 통해 시스템 병목을 예방하고 무중단 결제를 실현하겠습니다. 둘째, 대량의 DB I/O 병목 현상을 겪는 이커머스 및 물류 시스템 구조를 분석하고 Write-behind 캐싱 전략을 적용하여 데이터 정합성 보장과 조회 속도 개선에 기여하겠습니다.

## 2. 프로젝트를 완수하기 위해 노력한 경험을 구체적으로 소개해 주세요. (최소 300자, 최대 700자)
*작성방법 : ① 프로젝트 종류 / 규모 / 본인 역할 및 기여도 / 수행 과정 / 배운 점 포함) ② 직무 관련 과제/대외활동/동아리/인턴경험/개인 프로젝트 등 규모 및 종류에 관계 없이 작성 가능*

**[이론을 실무로 승화해 마친 11개월의 경진대회]**
웹 프론트엔드, AI 연구원 등 총 4명으로 구성된 팀에서 11개월간 기업연계 리밸런싱 플랫폼 개발 프로젝트를 진행했습니다. 저는 유일한 백엔드 개발자이자 DB 설계자로서 API 전체 및 DB 아키텍처를 총괄하며 경진대회 동상 수상과 특허 출원이라는 최종 성과를 견인했습니다.

수행 과정에서 두 번의 병목을 해결했습니다. 첫째, 단일 테이블 위주의 설계로 데이터 중복과 외래키 삭제 시 참조 무결성이 붕괴하는 문제가 있었습니다. 정보처리기사 이론에서 학습한 DB 정규화를 적용해 테이블을 3차 정규화까지 분해하고, JPA Cascade 및 고아 객체 삭제 옵션을 최적화하여 무결성을 100% 확보했습니다. 둘째, Flask AI 서버에 리밸런싱 추천 연산을 요청할 때 동기식 통신으로 인한 스레드 고갈 병목을 겪었습니다. 이를 위해 WebClient 논블로킹 통신을 전면 도입하고, @Async 기반의 독립된 AI 전용 스레드 풀을 격리 구성함으로써 메인 작업 스레드 점유율을 0ms로 낮춰 동시 요청 환경에서도 서버 다운을 원천 방어했습니다.

이 경험을 통해 학술적 이론이 시스템 안정성에 미치는 중요성을 배웠으며, 문제 해결을 위해 대안을 찾아 적극적으로 시도하는 엔지니어링 자세를 길렀습니다.

## 3. 본인 삶의 가치관 한 가지를 소개하고, 이를 회사에서 실현할 수 있는 방법을 작성해 주세요. (최소 300자, 최대 700자)
*작성방법 : ① 본인의 가치관 ② 회사에서의 가치관 실현 방법 포함*

**[리스크를 예방하는 사전 구조화의 가치]**
"장애와 갈등은 사후에 조치하기보다, 사전에 구조와 시스템을 구축하여 예방하는 것이 가장 생산적이다"라는 가치관을 가지고 있습니다. 이전 프로젝트에서 사전 조율이 부족하여 프론트엔드와 백엔드 간 인터페이스 마찰로 일정이 지연된 경험이 있었습니다. 이를 극복하고자 다음 프로젝트에서는 코드를 작성하기 전에 API 스펙, 에러 코드 규격, DB 스키마를 세부 조율하고 Notion에 문서화해 '단일 진실 공급원(SSOT)'으로 정착시켰습니다. 그 결과 서로의 작업 충돌과 재작업 비용을 원천 차단하며 성공적으로 완수했습니다.

이 가치관을 롯데홈쇼핑에서 실현하는 방법은 두 가지입니다. 첫째, 홈쇼핑IS팀의 핵심 미션인 24시간 무중단 서비스를 달성하기 위해 장애 요인을 사전에 시나리오별로 발굴하고 방어 코드를 적용하는 선제적 예방 관리를 실천하겠습니다. DB 쿼리 설계 단계부터 인덱스 적절성 및 실행 계획을 사전에 검증하여, 방송 트랙픽 급증 시의 락(Lock)이나 시스템 마비 리스크를 차단하겠습니다. 둘째, 현업 MD, CS, 물류부서 등 다양한 유관 조직과 협업 시 요구사항을 정밀한 문서로 자산화해 소통 오류를 제로화하고 프로젝트 효율성을 극대화하겠습니다. 이러한 선제적 구조화 가치관을 바탕으로 비즈니스 안정성을 사수하는 든든한 백엔드 엔지니어가 되겠습니다.
