### 3. 해당 직무에 지원하신 이유, 본인이 적합하다고 판단하는 근거, 관련 산출물 등을 작성해주세요. (900자 이하)

**[40%의 쿼리 응답 속도를 개선한 성능 최적화 역량]**
데이터베이스 엔지니어(DBA) 직무에 지원한 이유는, 애플리케이션의 성능과 서비스의 신뢰성을 결정짓는 가장 핵심적인 뼈대가 바로 데이터베이스 아키텍처와 SQL 성능에 있다고 믿기 때문입니다. 아무리 유려한 프론트엔드도 DB 병목 앞에서는 무용지물이 됨을 경험하며, 근본적인 성능 한계를 극복하는 DBA의 역할에 매력을 느꼈습니다.

저는 다음과 같은 성능 튜닝 경험을 통해 이 직무에 적합한 역량을 증명해 왔습니다. 
진행했던 프로젝트 중 대량의 금융 데이터를 조회할 때 트래픽 병목 현상으로 응답 지연 문제가 발생한 적이 있습니다. 이 문제를 해결하기 위해 가장 먼저 DBMS의 실행 계획(Execution Plan)을 심층적으로 분석했습니다. 그 결과, 비효율적인 풀 스캔(Full Scan)이 발생하여 디스크 I/O가 급증하는 것이 병목의 주원인임을 파악했습니다.

이후 데이터의 접근 패턴과 카디널리티(Cardinality)를 고려하여 복합 인덱스를 새롭게 설계하고 적용했습니다. 또한 서브쿼리 남용을 줄이고 조인(Join) 방식을 최적화하는 방향으로 쿼리 구조를 전면 재작성하는 과정을 거쳤습니다. 이러한 끈질긴 튜닝의 결과, 기존 대비 쿼리 응답 속도를 40% 이상 대폭 개선하여 트래픽 병목을 해소하는 괄목할 성과를 낼 수 있었습니다. 

이러한 산출물을 통해 저는 쿼리의 겉모습이 아닌 실행 계획의 이면을 들여다보는 분석력과, DBMS의 구조적 특성을 이해하고 성능을 극대화하는 최적화 역량을 길렀습니다. 이러한 저의 실전 튜닝 경험과 구조적 문제 해결 능력은 초당 수많은 트랜잭션이 발생하는 키움증권 DBMS 환경에서 성능 저하를 방지하고 최상의 데이터 응답성을 보장하는 데 즉각적으로 기여할 것입니다.
