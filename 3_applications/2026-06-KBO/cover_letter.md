# [KBO] 미디어사업팀 - KBO앱 데이터 관리·분석 지원 자기소개서

### [자기소개서 문항] 작성하고 싶은 내용을 자유롭게 기술해 주시기 바랍니다. (최대 5,000자 제한)

#### [팬 퍼스트(Fan First)의 실현을 위한 데이터 기반의 스포츠 미디어 혁신]
한국야구위원회(KBO)는 1,000만 관중 시대를 넘어서며 팬덤 기반의 스포츠 엔터테인먼트 산업으로 자생적 패러다임 전환을 선도하고 있습니다. 티빙(TVING)과의 뉴미디어 중계권 계약 및 구속, 발사각 등 경기 트래킹 데이터의 실시간 시각화는 팬 경험을 극대화하려는 KBO의 확고한 혁신 의지를 보여줍니다. 저의 비전은 백엔드 및 데이터 엔지니어링 기술력을 기반으로 사용자 행동 데이터를 정교하게 정제하고 분석하여, 기술과 사람을 잇는 고부하 플랫폼을 완성하는 것입니다. KBO의 공식 플랫폼인 KBO 앱은 수많은 야구 팬들의 실시간 교류와 콘텐츠 소비가 이뤄지는 비즈니스의 핵심 접점입니다. 저는 대학에서 컴퓨터공학을 전공하며 쌓아온 SQLD 및 정보처리기사 수준의 데이터베이스 설계 지식과 대용량 비동기 통신 아키텍처 경험을 결합하여, KBO 앱의 서비스 안정성을 확보하고 데이터 기반의 AI 개인화 서비스 초석을 다지기 위해 지원했습니다.

#### [하이브리드 AI 주식 리밸런싱 플랫폼을 통한 고성능 데이터 아키텍처 구현 및 비동기 연동 경험]
저는 학술적 DB 이론을 실제 대용량 데이터 파이프라인에 대입하여 아키텍처를 개선한 실무 역량을 보유하고 있습니다. 약 11개월 동안 4인 프로젝트로 '하이브리드 AI 주식 리밸런싱 비율 추천 서비스'의 백엔드 API 설계 및 데이터베이스 구축을 전담하며 데이터 정합성과 동시성 문제를 기술적으로 해결했습니다.

당시 플랫폼은 Temporal Graph Neural Network(TGNN)와 DDPG 강화학습 기반의 AI 예측 모델을 연동하여 개인 맞춤형 리밸런싱 비율을 산출해야 했습니다. 하지만 초기 설계 단계에서 (1) 단일 테이블 위주의 설계로 인한 중복 컬럼 발생 및 데이터 참조 무결성 붕괴, (2) 부모 레코드 삭제 시 자식 데이터가 남아 수동 데이터 추적 리소스가 낭비되는 이상 현상, (3) 수 초 이상 소요되는 AI 모델 추론 연산 시 톰캣(Tomcat) 작업 스레드가 고갈되어 메인 API 서버가 마비되는 동기식 병목 문제가 존재했습니다.

이를 해결하기 위해 첫째, 데이터베이스 논리적 정규화(1NF -> 2NF -> 3NF)를 순차적으로 적용했습니다. 중복 컬럼을 제거하고 이행적 함수 종속성을 제거하여 `User`, `Account`, `Portfolio`, `Rebalancing` 등의 독립 테이블로 도메인 경계를 명확히 획정했습니다. 또한 JPA 연관관계 매핑 시 `cascade = CascadeType.ALL` 및 `orphanRemoval = true` 설정을 엄격히 지정하여 부모 삭제 시 자식 데이터가 안전하게 전파 삭제되도록 참조 무결성을 완전히 확보했습니다.

둘째, AI 서버와의 연동 성능 최적화를 위해 스프링의 `WebClient`를 활용한 논블로킹(Non-blocking) 비동기 파이프라인을 구축했습니다. AI 추론 요청 처리가 웹 서비스의 메인 API 서버 스레드 풀에 미치는 간섭을 격리하기 위해, `ThreadPoolTaskExecutor`를 설정하여 **AI 전용 비동기 스레드 풀(Thread Pool Isolation)**을 설계했습니다. 핵심 비즈니스 로직에 `@Async("aiExecutor")`를 도입함으로써 무거운 연산이 수행되는 동안에도 톰캣 스레드의 차단 시간(Blocking Time)을 0ms로 완벽히 제어하여 대용량 분산 환경에서의 요청 처리 안정성을 입증했습니다.

그 결과, 해당 프로젝트로 **기업연계 프로젝트 우수팀 경진대회 동상(4등)**을 수상하고, 하이브리드 AI 시스템 설계의 독창성을 입증받아 **공식 특허 출원**을 완료했습니다. 이 경험을 통해 데이터 정합성을 확보하는 아키텍처 리팩토링 능력을 체득했습니다.

#### [데이터 기반의 의사결정과 KBO 앱 고도화를 이끄는 협업 리더십]
입사 후 KBO 미디어사업팀에서 다음과 같은 구체적인 실행 계획을 통해 조직의 발전에 기여하겠습니다.

첫째, **데이터 기반의 업무 자동화 및 리포트 작성 지원**을 실현하겠습니다. KBO 앱에서 발생하는 방대한 사용 로그 및 콘텐츠 트래픽 데이터를 수동으로 정리하는 비효율을 개선하기 위해, SQL 및 Python 스크립트를 활용한 데이터 정제(ETL) 프로세스를 정립하겠습니다. Excel 보고서 작성을 자동화하여 핵심 비즈니스 지표(이탈률, 잔존율, 콘텐츠 클릭 추이 등)를 매끄럽게 모니터링할 수 있는 내부 업무 인프라를 구축하겠습니다.

둘째, **KBO 앱의 기술적 페인 포인트 개선 및 개인화 모델 선제 제안**을 주도하겠습니다. 최근 앱 스토어 리뷰를 분석한 결과, 로그인 지연 및 화면 로딩 오류 등 안정성에 대한 사용자의 불만이 접수되고 있습니다. 백엔드 지식을 바탕으로 병목 현상이 발생하는 API 레이어를 추적하고, 리소스를 낭비 없이 제어할 수 있는 구조적 대안(예: 비동기 데이터 로딩, 자주 조회되는 경기 지표의 캐싱 처리)을 제안하겠습니다. 나아가 생성형 AI 및 추천 서비스 사례를 벤치마킹하여 '사용자의 선호 구단/선수 기반 맞춤형 하이라이트 푸시 알림'과 같은 데이터 기반 개인화 아이디어를 기획에 반영하겠습니다.

셋째, **기술과 기획의 언어를 잇는 협업 문화**를 만들겠습니다. 프론트엔드, 백엔드, AI 엔지니어 간의 API 명세 설계 및 이벤트 스키마 공유 경험을 살려, KBO의 행정·비즈니스 부서와 개발 협력사 사이의 가교 역할을 충실히 수행하겠습니다. 명확한 문서화(Documentation)와 데이터 정의서 표준화를 통해 프로젝트 소통 비용을 50% 이상 절감하여 혁신적인 아이디어가 기역에서 실행까지 막힘없이 이어지도록 기여하겠습니다.
