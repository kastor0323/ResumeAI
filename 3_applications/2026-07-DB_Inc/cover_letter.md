## 1. 지원하신 직무에 관심을 갖게 된 계기와, 해당 직무를 성공적으로 수행하기 위해 그동안 어떤 노력을 기울여 왔는지 본인의 강점을 바탕으로 기술해주세요. (최대 800자 입력가능)

**소제목: 고신뢰성 금융 백엔드 아키텍처를 향한 정합성과 성능의 탐구**

데이터 생명주기를 제어하며 시스템의 안정성을 지탱하는 백엔드 아키텍처에 흥미를 느껴왔습니다. 특히 금융 IT는 단 1건의 데이터 오차도 치명적이기에 완벽한 정합성을 지향하는 백엔드 역량의 중요성을 실감해 관심을 가졌습니다. 금융 AIT 기업으로 도약하는 DB Inc.는 제 정합성 및 성능 제어 역량을 가장 가치 있게 발휘할 터전이라 확신합니다.

이를 성공적으로 수행하고자 첫째, 데이터 무결성을 보장하는 설계 능력을 길렀습니다. 주식 거래 시스템 개발 시 ledger_entry를 단일 진실 공급원(SSOT)으로 두어 잔고 불일치를 차단했고, Redis 분산 락으로 고빈도 동시성 이슈를 제어했습니다. 또한 대용량 배치 처리 시 Cursor-based 페이지네이션을 도입해 누락을 방지하고 원장 정합성 불일치 0건과 75,000건 처리를 달성했습니다.

둘째, 대규모 연동 시의 병목을 해결하는 성능 최적화 역량을 다졌습니다. 주식 리밸런싱 비율 추천 서비스 개발 중, Flask AI 서버의 연산 지연으로 Tomcat 스레드가 고갈되는 병목을 해결하기 위해 WebClient 논블로킹 통신과 @Async 스레드 풀 격리를 구현해 동시 요청 상황에서도 메인 API 스레드 블로킹 시간을 0ms로 제어했습니다. 이처럼 탄탄히 다진 강점을 발휘하여 DB Inc.에서 무장애 금융 IT 서비스를 설계하는 엔지니어가 되겠습니다.

## 2. 다양한 배경을 가진 사람들과 공동의 목표를 달성하기 위해 협력했던 경험을 본인의 역할과 노력을 중심으로 기술해주세요. (최대 800자 입력가능)

**소제목: 사전 API 약속과 SSOT 문서화로 협업 마찰을 원천 차단하다**

팀 프로젝트의 진정한 효율성은 갈등이 일어난 뒤 조율하는 것이 아닌, 갈등이 발생하지 않도록 예방하는 시스템을 선제적으로 구축하는 데서 출발한다고 확신합니다.

4인 팀으로 하이브리드 AI 주식 리밸런싱 서비스 개발을 진행할 당시, 프론트엔드와 백엔드, AI 직군 간의 명세 조율이 어긋나 잦은 코드 수정과 소통 병목이 생겼던 과거 경험을 떠올렸습니다. 저는 이 갈등의 원인이 소통의 부재가 아니라 '합의된 사전 구조의 부재'라고 정의했습니다. 이를 해결하고자 본격적인 코딩을 시작하기 전, 팀원들을 소집하여 데이터베이스 스키마 설계, API 엔드포인트 및 Request/Response 스펙, 에러 코드 규격을 철저하게 사전에 정의했습니다. 그리고 이를 모두가 동일하게 신뢰할 수 있는 단일 진실 공급원(SSOT)으로 노션에 명문화하고 실시간 동기화했습니다.

그 결과 개발 중 발생하는 불필요한 상호 확인 비용을 최소화하고, 통합 단계에서의 인터페이스 불일치로 인한 재작업률을 제로에 가깝게 방어했습니다. 또한 Pull Request 기반의 크로스 코드 리뷰를 병행하여 품질을 확보한 결과, 최종적으로 전체 프로젝트 개발 기간을 약 20% 단축하는 유의미한 시너지를 창출했습니다. 서로 다른 배경을 지닌 조직원들과 유기적으로 소통하며 개발 효율을 극대화해 온 소통 능력을 바탕으로, DB Inc.의 다양한 유관 부서 및 고객사와의 연계 프로젝트에서도 주도적인 화합을 이끌어내겠습니다.

타인의 잠재된 불편함을 선제적으로 포착하고, 기준을 준수하되 개개인에 맞는 유연한 접근을 통해 실질적인 해결책을 제시하는 것에 집중합니다.

아웃백 스테이크 하우스에서 아르바이트를 하던 중, 처음 방문하셔서 복잡한 메뉴와 주문 시스템 앞에서 당황해하시는 연세가 지긋하신 고객님들을 목격했습니다. 저는 기계적인 메뉴얼식 설명이 오히려 고객님들의 선택을 더 방해할 수 있다고 판단하여, 먼저 친근하게 다가가 대화를 청했습니다. 평소 드시는 식사량은 어떠신지, 매콤한 맛을 선호하시는지 등 직관적이고 쉬운 질문을 통해 고객님들의 취향을 상세히 파악했습니다. 파악된 정보를 바탕으로 양과 맛을 모두 충족할 수 있는 최적의 세트 메뉴를 맞춤형으로 제안했고, 고객님은 저의 추천을 신뢰하여 만족스럽게 주문하셨습니다.
