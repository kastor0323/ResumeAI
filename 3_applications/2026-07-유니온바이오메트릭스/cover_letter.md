## 문항 1. 조직 적합성

단순히 눈에 보이는 화면을 구현하는 것을 넘어 데이터의 생명주기를 주도적으로 제어하는 설계자의 역할에 깊은 매력을 느껴 백엔드 개발자로서의 커리어를 걷기 시작했습니다. 클라이언트의 엔드포인트부터 데이터베이스에 이르기까지 데이터가 안전하게 가공되고 저장되는 전체 구조를 설계하며 MySQL 최적화와 정밀한 트랜잭션 제어를 학습해 왔습니다. 저의 이러한 데이터 모델링 지향점은 생체인식 보안 솔루션 전문 기업으로서 고객의 안전과 자산을 수호하는 유니온바이오메트릭스의 핵심 비전과 완벽하게 부합합니다.

유니온바이오메트릭스는 최근 하드웨어 제조를 넘어 클라우드 기반 출입보안 플랫폼인 알페타 X 및 반려동물 비문 인식 플랫폼 펫 아이디 등을 선보이며 혁신적인 플랫폼 기업으로 도약하고 있습니다. 특히 프랑스 데이터센터 기업과의 협력을 통한 글로벌 AI 데이터센터 보안 사업 확장과 방글라데시 아코테 그룹과의 글로벌 진출 업무협약 소식은 유니온바이오메트릭스가 글로벌 기술 인프라 보안 시장의 독보적인 선두 주자임을 증명합니다. 인공지능과 클라우드가 결합된 차세대 물리 보안 시스템에서는 초당 수많은 인증 트래픽과 이미지 매칭 데이터를 유실 없이 처리하는 뒷단의 견고함이 가장 중요합니다. 저는 시스템 트래픽의 병목을 해결하고 데이터 정합성을 철저히 보장할 수 있는 역량을 갈고닦아 왔습니다.

유니온바이오메트릭스 R&D부문 개발자로서 입사하여, 실시간 생체인증 요청과 펫 아이디의 대량 이미지 조회 트래픽 속에서도 병목 없이 쾌적한 서비스를 제공하는 고성능 백엔드 아키텍처 구축에 기여하겠습니다. 물리 보안 분야 특성상 사소한 트랜잭션 예외도 금융 사고나 보안 위협으로 이어질 수 있습니다. 데이터의 시작부터 소멸까지 완벽하게 통제하고, 무거운 트래픽 환경 속에서도 시스템 리소스를 최적화하여 글로벌 데이터센터와 사용자들이 신뢰하고 사용할 수 있는 웹 보안 인프라를 지탱하겠습니다.

## 문항 2. 직무 적합성

비동기 파이프라인과 DB 정규화로 고성능 AI 웹 서비스를 설계하다

하이브리드 AI 주식 리밸런싱 비율 추천 모바일 서비스를 개발하는 프로젝트에서 웹 서버 설계와 데이터베이스 구축을 전담하며 백엔드 실무 기술 역량을 증명했습니다. 당시 시스템의 안정성을 저해하는 두 가지 당면 과제가 있었습니다. 첫째는 설계 결함으로 인한 데이터 무결성 오류와 외래키 처리 누락에 따른 고아 데이터 발생 문제였고, 둘째는 딥러닝 추론 연산이 밀릴 때 톰캣 스레드가 고갈되어 전체 API 서버가 먹통이 되는 병목 현상이었습니다.

이러한 문제를 주도적으로 해결하기 위해 먼저 이론으로 학습한 데이터베이스 정규화를 프로젝트에 실질적으로 적용했습니다. 반복 그룹 컬럼을 제거하여 회원, 계좌, 리밸런싱 등의 개별 테이블로 분리하는 제1정규화부터 부분 함수 종속성과 이행적 함수 종속성을 차례로 제거하는 제2, 제3정규화를 순차적으로 완수하여 데이터 정합성을 보장했습니다. 또한 JPA 연관관계에 영속성 전이와 고아 객체 제거 옵션을 설정하여 부모 레코드 삭제 시 자식 데이터가 결정론적으로 전파 삭제되도록 설정함으로써 무결성을 확보했습니다.

이후 가장 치명적이었던 AI 모델의 병목을 해결하고자 스프링 웹클라이언트 기반의 논블로킹 통신을 도입했습니다. 수 초가 소요되는 AI 모델 추론 요청을 동기식으로 호출할 경우 발생하는 톰캣 스레드 고갈 리스크를 해소하기 위해, 별도의 비동기 스레드 풀을 격리 구성하고 웹클라이언트로 Flask AI 서버를 비동기 호출하도록 아키텍처를 설계했습니다. 이를 통해 대규모 동시 요청 환경에서도 메인 API 스레드의 블로킹 시간을 0ms로 유지하는 성능 최적화를 달성했습니다. 그 결과 기업연계 우수팀 경진대회에서 동상을 수상하고 하이브리드 AI 모델 관련 특허를 공동 출원하는 정량적 성과를 거두었습니다. 유니온바이오메트릭스의 비문 인식 및 생체인증 웹 솔루션에 이러한 AI 연동 및 성능 최적화 역량을 즉시 이식하겠습니다.

## 문항 3. 의사소통 방식 및 협업

단일 진실 공급원 구축을 통한 선제적 소통 시스템의 구현

진정한 협업 효율성은 개발 과정에서 발생할 수 있는 마찰을 사전에 예방하는 소통 구조의 구축 여부에 달려있다고 믿습니다. 과거 개발 프로젝트를 진행할 때 API 스펙과 데이터베이스 구조를 명확히 정의하지 않고 코딩에 착수했다가, 프론트엔드와 백엔드 간의 인터페이스 불일치로 인해 잦은 재작업과 소통 병목을 겪으며 개발 일정이 심각하게 지연되는 갈등을 경험했습니다.

저는 이러한 마찰의 원인이 단순한 의사소통 부족이 아니라 모든 팀원이 신뢰할 수 있는 공통된 아키텍처 기준이 없기 때문라고 진단했습니다. 이를 해결하기 위해 하이브리드 AI 주식 리밸런싱 앱 개발 프로젝트에서는 본격적인 코딩을 시작하기 전, 팀원들과 함께 DB 스키마, 요청과 응답 스펙, 에러 코드 규격을 철저히 사전 정의하여 공유 문서로 명문화했습니다. 이 문서를 모든 팀원이 실시간으로 확인하는 단일 진실 공급원(SSOT)으로 정착시켰습니다. 개발 중 의문이 생기면 서로 구두로 묻기 전에 문서를 확인하는 문화를 구축했고, 변경 사항 발생 시 반드시 사전 논의를 거쳐 문서를 우선 업데이트했습니다.

이러한 사전 예방적 소통 구조를 정착시킨 결과, 팀 내 인터페이스 불일치로 인한 재작업률을 제로에 가깝게 줄였습니다. 동료들은 구현 단계에서 불필요한 소통 혼선이 완전히 사라져 개발 피로도가 크게 낮아졌고, 각자 기능의 완성도에만 온전히 집해 최고의 개발 시너지를 낼 수 있었다며 매우 만족스러운 피드백을 보냈습니다. 소통 오해로 인한 감정적 마찰이나 불필요한 질의 리소스 소모를 원천 차단했고, 전체 프로젝트 일정을 초기 계획 대비 약 20% 단축하는 성과를 도출했습니다. 유니온바이오메트릭스는 다양한 생체보안 솔루션을 복합적으로 개발하고 수많은 외부 디바이스 및 시스템과 연동하는 만큼 아키텍처 정렬이 필수적입니다. 협업 마찰을 선제적으로 예방하는 소통 역량으로 원활한 프로젝트 완수를 주도하겠습니다.
